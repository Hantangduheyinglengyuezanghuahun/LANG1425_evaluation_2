01 / 引入与访谈背景

媒介迁移不是沟通方式的简单平移

线上沟通提供准备时间和检索便利；线下交流提供语气、表情、肢体动作及即时反馈。本研究追问：差异体现在哪些维度？造成了什么挑战？个体应如何应对？

02 / 主要问题发现

两大双向挑战

线上线下人际交往的挑战，沿信息传递与接收落差展开。

01

情感传递损耗

文字剥离语气、表情和肢体动作；表情包只能部分代偿。理性表达可能被误读为冷漠或反驳，同一句话也会因语境不同而改变含义。

↗
02

时机与期待错位

回复延迟可能被误判为态度冷淡；等待期产生焦虑和关系猜测。线上结束对话较容易，线下拒绝请求与结束对话可能更难。

↗

两者不是孤立现象：信息损耗导致误解，时机错位放大焦虑，共同构成沟通中的认知偏差。

03 / 问题深度分析

是什么 → 为什么 → 导致什么结果

从受访者的具体经历出发，解释沟通问题产生的机制。

问题一 / 情感传递损耗

线索减少，理解更难

线上文字可以反复斟酌，却较难同时传递语气、表情、肢体动作和即时反馈。PPT 用媒介丰富度、自我呈现与社会存在三个视角解释这种损耗。

问题二 / 时机与期待错位

看见回复，看不见状态

发消息时不知道对方正在做什么；延迟出现后，缺少的情境容易被自己的关系猜测填补。另一方面，异步交流也给拒绝请求和斟酌回复留下缓冲。

04 / 解决方法与总结

根据沟通需要选择方式

同时考虑双方习惯、时间和距离。下列做法来自 PPT 的建议性框架。

01 / 通知与资料分享

用文字保留记录

通知、资料分享与确认安排适合用文字，方便整理、检索和保留记录。

先说明问题 → 约定时间 → 讨论 → 线上确认结论
02 / 情感表达不清

补充线索并确认理解

先用文字说明感受和意图；如果仍有误解，商量改用语音、视频或面谈。交流中确认对方的理解。

访谈 B：理性回应在线上曾被误解为反驳或否定情绪。
03 / 时空错位

提前约定专心交流的时间

说明事务的期限和紧急程度。需要认真讨论时，约双方都能专心的时间；回复延迟时先核实处境。

访谈 C：同学回复缓慢，后来才知道对方正在赶 PPT。

INTERVIEW / A · 普通话

访谈 A 摘要

受访者认为，与不熟悉的人交流时，线上表达更放松，也有时间斟酌措辞；线下则较拘谨，容易顾及气氛和他人感受。文字缺少语气、表情及动作，表情包虽能辅助表达，却难以充分传递情绪强度。他会因等待回复而紧张，也可能把快速回复理解为受到重视。面对面交流更容易延伸话题、深入了解彼此，但维持气氛和结束对话也会带来压力。他倾向在线上处理学习、工作和资料交换，在线下进行复杂讨论，并强调选择沟通方式时应考虑对方的习惯。
INTERVIEW / B · 粤语

访谈 B 摘要

受访者认为，线上交流有时间准备和搜索素材，因此用词、例子和网络梗更丰富；线下回应较依赖惯常表达。文字能够传递情感，但复杂情绪需要更多解释，也较容易隐藏真实感受。他曾用逻辑和论据回应别人，却在线上被误解为反驳或否定情绪；面对面时，语气和表情有助于减少误会。他不太介意慢回复，但知道朋友的期待各不相同。他认为线上适合低成本破冰和日常联系，线下适合共情及即时协调；发生误会后，应解释原意，通过沟通确认彼此的理解。
INTERVIEW / C · 普通话

访谈 C 摘要

受访者认为，线上便于表达整理后的想法，但难以了解对方回复时的处境。他曾误解高中同学回复缓慢，后来才知道对方正在赶次日汇报的PPT。他指出，有限信息容易使人想象对方的形象，关系判断应结合长期相处、可靠性、支持和边界，不能只看聊天频率或回复速度。面对面也可能增加拒绝请求的压力，因此需要说明时间和能力限制。他建议根据话题和双方状态安排交流，先用文字说明问题、约定时间，再通话或面谈，最后确认安排；先核实意思，再判断态度。
