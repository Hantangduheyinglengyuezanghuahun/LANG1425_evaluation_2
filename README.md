# LANG 1425 Evaluation 2

This repository contains interview materials and three short interview summaries for our class project.

## Blog demo

The static demo is in [`docs/`](docs/index.html). Its four sections follow the latest presentation: introduction and interview background, two main challenges, deeper analysis, and solutions. The appendix links to all three full transcripts, both recordings, and both consent-form PDFs in this repository.

To preview locally, serve the repository root with a static HTTP server and open `/`. For example, run `python -m http.server 8000` inside this repository, then visit `http://localhost:8000/`. A server is needed for linked audio and transcript pages.

To publish with GitHub Pages, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. The resulting URL will follow `https://<username>.github.io/LANG1425_evaluation_2/`. The root page redirects to the blog in `/docs/`, while the root also serves the original records, audio, and PDFs.

To download the project files, use the green **Code** button and choose **Download ZIP**.
